# راهنمای آزمون برنامه با گوشی واقعی

شبیه‌ساز اندروید بلوتوث ندارد؛ این آزمون‌ها با **دو گوشی** انجام می‌شوند: گوشی **A** استاد و گوشی **B** دانشجو.
برای آزمون «استاد جعلی» یک گوشی سوم (**C**) هم لازم است.

## ۱. آماده‌سازی

### نصب
- **Android Studio:** پروژه را باز کنید، گوشی را با کابل وصل کنید و ▶ (Run) را بزنید؛ برای هر گوشی جدا.
  اگر Gradle خطا داد: `Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK = 17`
- **یا فایل نصبی:** `app/build/outputs/apk/debug/app-debug.apk` را به گوشی بفرستید و نصب کنید، یا:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### پیش از شروع
- **نسخه یکسان:** در هر دو گوشی منوی ⋮ ← «درباره برنامه» را باز کنید؛ نسخه و پروتکل باید یکی باشد (مثلاً «نسخه ۲.۰ (پروتکل ۳)»).
- بلوتوث روشن؛ در **اندروید ۱۰ و ۱۱ موقعیت مکانی (GPS) هم روشن** (بدون آن اندروید گوشی استاد را پیدا نمی‌کند).
- گوشی دانشجو **قفل صفحه** (اثر انگشت یا رمز) داشته باشد.
- «صرفه‌جویی باتری» خاموش.
- مجوزهای «دستگاه‌های نزدیک»، «اعلان» و «دوربین» را **اجازه** بدهید.

### راه‌اندازی
1. **A:** «استاد» ← نام و نام درس ← ورود. کد کلاس (مثل `JTS58-H3K5H`) را یادداشت کنید.
2. **A (اختیاری):** تب «درس‌ها» ← «لیست کلاس» ← فایل Excel با ستون‌های کد دانشجویی و نام (کد دانشجویی B هم داخلش باشد).
3. **B:** «دانشجو» ← نام، کد دانشجویی و کد کلاس ← ورود.

## ۲. مراحل آزمون

| # | آزمون | کار شما | نتیجه درست |
|---|---|---|---|
| ۱ | ثبت حضور ساده | A: «شروع حضور و غیاب». B: «ثبت حضور» و تایید اثر انگشت | B: «حضور شما ثبت شد»؛ اسم B در «حاضرین» A |
| ۲ | ثبت تکراری | B دوباره «ثبت حضور» بزند | «قبلاً ثبت شده»؛ اسم تکراری در A نمی‌آید |
| ۳ | اثر انگشت امضا | A: درس‌ها ← «نمایش کد». B: «درس‌های من» | عدد ۱۶ رقمی «امضای این گوشی» در هر دو یکی |
| ۴ | کد کلاس اشتباه | B فقط درسی با کد کلاس دیگر داشته باشد و ثبت حضور بزند | «گوشی استاد پیدا نشد»؛ حضوری ثبت نمی‌شود |
| ۵ | پس‌زمینه | A: شروع و **قفل صفحه**؛ ۱۰ دقیقه بعد B ثبت کند | ثبت موفق؛ در اعلان A «حاضر امروز» یکی بیشتر |
| ۶ | توقف از اعلان | A: نوار اعلان ← «توقف» | حضور و غیاب متوقف؛ B دیگر نمی‌تواند ثبت کند |
| ۷ | محدوده کلاس | A: «تنظیمات جلسه» ← «کلاس کوچک». B از ۱، ۵، ۱۰ و ۲۰ متری | نزدیک: ثبت؛ دور: «از گوشی استاد دور هستید» |
| ۸ | QR چرخشی | A: «تنظیمات جلسه» ← «QR الزامی باشد» ← شروع ← «نمایش QR به کلاس». B: «ثبت حضور» | دوربین B باز می‌شود؛ بعد از اسکن، حضور ثبت می‌شود |
| ۹ | عکس QR کهنه | از QR عکس بگیرید؛ ۴۰ ثانیه بعد دانشجوی دیگری عکس را اسکن کند | «QR کهنه یا نامعتبر بود» |
| ۱۰ | ثبت دستی و حذف | A: «غایبین» ← لمس یک نفر ← حاضر؛ «حاضرین» ← لمس ← حذف | لیست و آمار درست تغییر کند |
| ۱۱ | خروجی Excel | A: «گزارش» ← «خروجی Excel» | فایل در Excel یا Google Sheets باز شود؛ جدول دانشجو × جلسه و تعداد غیبت |
| ۱۲ | پشتیبان و بازیابی | A: ⋮ ← «پشتیبان‌گیری» ← «خروج و حذف اطلاعات» ← ورود استاد ← «بازیابی از پشتیبان». سپس B ثبت کند | درس‌ها با همان کد برمی‌گردند؛ B **بدون هیچ تغییری** ثبت می‌شود |
| ۱۳ | استاد جعلی (C) | از فایل پشتیبان A بخش `"signingKey"` را پاک کنید؛ روی C به‌عنوان استاد وارد شوید، آن را بازیابی و حضور را شروع کنید؛ A خاموش؛ B ثبت حضور بزند | B **رد می‌کند**: «امضایش با گوشی استاد این درس یکی نیست» |
| ۱۴ | سابقه حضور | B: «درس‌های من» ← لمس کارت درس | جلسه‌ها با تاریخ شمسی، روز هفته و ساعت |

در آزمون ۱۳ گوشی C همان کد کلاس را دارد ولی کلید امضای دیگری؛ دقیقاً همان هم‌کلاسی متقلب.

## ۴. اگر کار نکرد

| پیام یا مشکل | علت و راه‌حل |
|---|---|
| «نسخه برنامه گوشی استاد با این گوشی فرق دارد» | نسخه یکسان را روی هر دو گوشی نصب کنید (⋮ ← «درباره برنامه» را مقایسه کنید) |
| «پیام گوشی استاد ناقص رسید» | ارتباط بلوتوث قطع و وصل شده؛ نزدیک‌تر شوید و دوباره بزنید. اگر تکرار شد، مدل هر دو گوشی را یادداشت کنید |
| «امضای گوشی استاد … معتبر نیست» | گوشی دیگری با همین کد کلاس روشن است، یا داده خراب رسیده؛ دوباره امتحان کنید و اگر تکرار شد گزارش دهید |
| «امضایش با گوشی استاد این درس یکی نیست» | گوشی استاد عوض شده (بدون پشتیبان) یا استاد جعلی است؛ اگر استاد واقعاً گوشی عوض کرده، دانشجو درس را حذف و دوباره اضافه کند |
| «گوشی استاد پیدا نشد» | بلوتوث و (در اندروید ۱۰ و ۱۱) موقعیت مکانی روشن؛ حضور و غیاب در A شروع شده باشد؛ نزدیک‌تر شوید |
| «از گوشی استاد دور هستید» از فاصله نزدیک | محدوده را «کلاس معمولی» یا «بدون محدودیت» کنید؛ عدد واقعی را در جدول بنویسید |
